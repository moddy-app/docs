# AI and language tools

Moddy provides assistance tools for text and audio. They are intended to speed up a task, not replace your review or judgement.

## Translation

`/translate` translates text to the selected language. Check proper names, community terms, and sensitive wording before publishing.

## Improve text

- `/fix` corrects spelling and grammar.
- `/rephrase` rewrites text in the requested style.
- `/summarize` creates a shorter version of text.

These commands can use an input interface to keep channel messages readable.

## Transcribe a voice message

The **Transcribe** action on a voice message and the Voice Transcription module convert supported audio into text. The module lets you choose manual or automatic operation and relevant channels.

## Privacy and availability

These features can be subject to quotas, server configuration, and third-party provider availability. Do not submit sensitive information to a tool if you do not want it processed by an external service.
