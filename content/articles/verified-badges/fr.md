# Les badges Moddy

Les badges Moddy aident à identifier les comptes liés à une organisation vérifiée, à l’équipe Moddy ou à certains programmes de la communauté. Ils sont affichés dans les interfaces Moddy compatibles, notamment les fiches de profil.

## Badges de vérification

Les badges de vérification suivent un ordre de priorité : un compte ne reçoit que le niveau le plus représentatif dans son nom affiché.

### Organisation vérifiée

Le badge **Organisation vérifiée** identifie une organisation reconnue par Moddy. C’est le niveau de vérification le plus élevé.

### Membre d’organisation ou d’équipe

Le badge **Vérifié** peut identifier un membre d’une organisation vérifiée, un membre de l’équipe Moddy ou un compte Discord du personnel reconnu. Lorsqu’une affiliation d’organisation est disponible, Moddy peut l’indiquer dans le profil.

### Compte vérifié

Le badge **Vérifié** peut aussi indiquer qu’un compte a été certifié par Moddy sans être présenté comme une organisation ou son membre.

> Un badge ne remplace pas votre vigilance : vérifiez toujours l’identité d’une personne pour une demande sensible, même lorsqu’un profil affiche un badge.

## Badges de communauté

Selon son statut, un profil peut également afficher des badges tels que **Premium**, **Partenaire**, **Contributeur**, **Bug Hunter** ou **Certifié**. Ils mettent en valeur une relation ou une contribution à Moddy ; ils ne donnent pas, à eux seuls, de permission particulière dans un serveur.

## Badges d’équipe

Les profils de l’équipe peuvent afficher un rôle interne, par exemple Développeur, Manager, Modérateur, Support, Communication ou Supervision. Ces badges permettent de reconnaître le rôle présenté par Moddy ; les permissions réelles restent contrôlées par les systèmes de sécurité et de rôles.

## Obtenir ou signaler un badge

Les badges sont attribués par les processus Moddy prévus à cet effet. Ils ne peuvent pas être réclamés par une commande publique. Pour signaler une usurpation ou poser une question sur un badge, contactez l’équipe via le serveur support officiel.
