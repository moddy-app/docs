# Command reference

This page summarises Moddy's main visible commands. Availability depends on context, app installation, and your Discord permissions.

## Information and utilities

| Command | Use |
| --- | --- |
| `/ping` | Checks Moddy availability and latency. |
| `/user` | Looks up public information about an account or bot. |
| `/avatar`, `/banner` | Show available profile media. |
| `/invite` | Looks up an invite. |
| `/emoji` | Inspects and manages emojis according to your permissions. |
| `/roll` | Runs a random draw. |
| `/translate` | Translates text. |

## Personal tools

| Command | Use |
| --- | --- |
| `/preferences` | Sets options including your incognito preference. |
| `/reminder` | Creates or manages reminders. |
| `/saved-messages` | Opens saved messages. |
| `/subscription` | Shows subscription status. |
| `/webhook` | Inspects and manages accessible webhooks. |

## Text, audio, and moderation

| Command or action | Use |
| --- | --- |
| `/fix`, `/rephrase`, `/summarize` | Correct, rewrite, or summarise text. |
| **Transcribe** | Transcribes a supported voice message. |
| `/cases`, `/mycases` | Opens server cases or your own cases. |
| `/clear-saved-roles`, `/view-saved-roles` | Administer saved roles. |

## Server administration

| Command | Use |
| --- | --- |
| `/config` | Opens server module configuration. |
| `/altguard verify`, `/altguard unverify` | Manually intervenes in an AltGuard verification. |

Staff and development commands are intentionally absent from this public reference: they are limited to authorised teams.
