# Bien démarrer avec Moddy

Moddy est une application Discord destinée aux communautés qui veulent réunir modération, automatisation et outils utiles dans une seule interface.

## Installer Moddy

Ajoutez Moddy à votre serveur depuis son lien d’installation, puis vérifiez que son rôle possède les permissions nécessaires aux fonctions que vous activez. Pour la modération, placez son rôle au-dessus des rôles qu’il doit gérer.

## Ouvrir la configuration

Utilisez `/config` dans votre serveur. Ce panneau est le point d’entrée de tous les modules : il affiche uniquement les réglages disponibles pour le serveur courant et permet de les enregistrer sans commandes complexes.

## Choisir la confidentialité des réponses

Les commandes personnelles proposent souvent l’option **incognito**. Lorsqu’elle est activée, la réponse n’est visible que par vous. Votre préférence par défaut est modifiable avec `/preferences`.

## Premiers réglages recommandés

1. Configurez un canal de journalisation pour les fonctions de modération.
2. Activez les modules dont votre communauté a réellement besoin.
3. Testez les actions avec un compte de test avant de les appliquer à tous les membres.
4. Vérifiez les permissions Discord du bot après chaque changement de rôles.

> Les fonctions qui modifient des membres, rôles ou messages restent soumises aux permissions Discord de votre serveur.
