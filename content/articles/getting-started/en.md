# Get started with Moddy

Moddy is a Discord application for communities that want moderation, automation, and useful tools in one place.

## Install Moddy

Add Moddy to your server using its install link, then make sure its role has the permissions required by the features you enable. For moderation, place its role above the roles it needs to manage.

## Open configuration

Run `/config` in your server. This panel is the entry point for every module: it shows settings for the current server and saves them without complex commands.

## Choose response privacy

Personal commands often include an **incognito** option. When enabled, only you can see the response. Change your default with `/preferences`.

## Recommended first steps

1. Configure a logging channel for moderation features.
2. Enable only the modules your community needs.
3. Test actions with a test account before applying them broadly.
4. Recheck the bot's Discord permissions after role changes.

> Features that manage members, roles, or messages always remain subject to your server's Discord permissions.
