# Configure your server

`/config` is the central home for Moddy modules. Each configuration belongs to the server where you open the panel.

## Manage modules

A module can be enabled, changed, or removed without affecting other modules. Panels show current selections and ask for confirmation before sensitive actions.

## Customise Moddy

The **Bot Customization** module can tailor the bot's identity for your server: nickname, avatar, banner, biography, and name style when Discord supports it. These settings do not affect other servers.

## Permissions

Configuration commands are limited to members who can manage the server. Some actions require additional permissions, such as managing roles or channels.

## A good approach

Start with one module, observe it, then expand gradually. Keep a log channel separate from community channels so you can review Moddy's actions.
